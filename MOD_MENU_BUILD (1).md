# GD Advance Mod Menu

This source adds an in-level cheat menu to the DEBUG build.

### Controls
- **L + R**: open menu
- **Up/Down**: select
- **A**: toggle/change
- **B**: close

### Cheats
- Noclip
- Hitbox display
- Speed: 0.5x / 1x / 2x / 3x / 4x

### Building
The repository includes `.github/workflows/build-mod.yml`. On GitHub, use **Actions → Build GBA mod → Run workflow**. The resulting `build/*.gba` is uploaded as the `gd-adv-mod` artifact.

The original source and ROM are not included in this patch archive.
